# AetherCore Zenith Issue Ledger

This ledger records confirmed and explicitly rejected findings from the Zenith adversarial pass. Severity describes product impact, not exploitability alone.

| ID | Subsystem | Severity | Confidence | Location | Defect / root cause | Failure scenario | Correction | Verification | Status |
|---|---|---:|---:|---|---|---|---|---|---|
| ZEN-001 | Fluid dialog / accessibility | High | High | `apps/ui/src/design/primitives/FluidDialog.svelte` | Reduced-motion close had two completion paths; preference/spring callbacks could report the same close more than once. | A close callback such as startup-restore finalization can execute twice, or a closed dialog can emit a spurious completion after preference changes. | Centralized close completion behind `completeClose()` and an idempotent `rendered` guard; the spring is the sole completion source. | `zenith-adversarial-audit.py`; Windows Svelte check/build and accessibility host qualification remain required. | FIXED |
| ZEN-002 | Press interaction | High | High | `apps/ui/src/design/motion/fluid-press.ts` | Pointer capture preserved tracking but native click activation was not fenced after drag-away cancellation. | User presses a dangerous/action button, drags outside to cancel, releases, yet the captured native click can still activate it. | Added capture-phase one-shot click suppression when release is unarmed; preserved keyboard activation; added reactive action options. | Zenith source regression + required Windows pointer/WebView2 interaction qualification. | FIXED |
| ZEN-003 | Drag physics | Medium | High | `apps/ui/src/design/motion/fluid-drag.ts` | `pointercancel` / lost capture were treated as intentional user releases and inherited sampled fling velocity. | OS/device cancellation can cause an element to project and fling after direct manipulation has already been aborted. | Split normal release from cancellation; cancellation settles with zero inherited velocity. | Zenith source regression + Windows pointer fault injection required. | FIXED |
| ZEN-004 | Update UX / accessibility | Medium | High | `apps/ui/src/features/system-care/SystemCarePanel.svelte` | Update channel selection was visual-only and progress duplicated a layout-width implementation without progressbar semantics. | Screen reader does not receive pressed state/progress value; frequent progress changes cause layout work instead of compositor transform. | Added `aria-pressed`; reused the existing semantic, spring-driven `ProgressBar`. | Zenith source regression; Svelte check/build required on Windows. | FIXED |
| ZEN-005 | Drivers UX / accessibility | Medium | High | `apps/ui/src/features/drivers/DriversPage.svelte` | Filter toggles exposed selected state only through styling. | Keyboard/screen-reader user can operate filters but cannot reliably determine the selected one. | Added `aria-pressed` to filter buttons. | Zenith source regression + accessibility host matrix. | FIXED |
| ZEN-006 | RTL diagnostics | Low | High | `CrashPage.svelte`, `HardwarePage.svelte`, `feature-layout.css` | Guided-action direction was embedded as a literal right arrow. | Arabic layout displays an LTR spatial cue that contradicts reading/navigation direction. | Moved cue to a semantic CSS class and mirrors `→`/`←` under RTL. | Zenith source regression + Arabic visual qualification. | FIXED |
| ZEN-007 | RTL progress motion | Low | High | `apps/ui/src/design/styles/motion.css` | Progress transform origin was not explicitly mirrored for RTL. | Arabic progress can visually grow from the wrong spatial edge depending on engine interpretation. | Explicit LTR left origin and RTL right origin. | Zenith source regression + WebView2 RTL visual qualification. | FIXED |
| ZEN-008 | Release governance | High | High | CI/release/production verification | Post-Enterprise UI fixes had no independent fail-closed source gate. | Future regression can pass historical Enterprise checks because they predate these exact interaction invariants. | Added platform-neutral Zenith audit, PowerShell wrapper, additive CI/release gate, GA prerequisite, and `verify-zenith.ps1`. | Zenith audit plus inherited Enterprise/Phase-16 gates. | FIXED |
