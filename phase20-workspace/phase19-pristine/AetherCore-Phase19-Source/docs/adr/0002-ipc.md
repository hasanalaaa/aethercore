# ADR-0002: Versioned protobuf over secured named pipes

**Status:** Accepted, amended in Phase 2

Use Protocol Buffers for a closed, typed message union and a local Windows named pipe for transport. The pipe rejects remote clients. Frames are length-prefixed and validated before allocation. Sensitive requests inspect the actual connected client PID instead of trusting a caller-supplied PID.

Phase 2 introduces full PnP snapshots, so framing is bounded by direction rather than one shared limit:

- requests: 256 KiB;
- responses: 8 MiB.

The smaller request cap preserves the attack-facing boundary because legitimate commands consist only of small typed IDs/parameters. The larger response cap accommodates hardware-rich inventory results without permitting unbounded memory use.
