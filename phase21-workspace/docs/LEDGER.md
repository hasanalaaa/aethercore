## How a cold session resumes

1. Read this file. Nothing else is required first.
2. Find the first row in **§1 Open work** whose status is not `CLOSED`.
3. Continue from it. Each row names its evidence and which machine it needs.
4. Move the row in the **same commit** as the work that moved it.

If a row needs a machine or a person you do not have, skip it — §3 says which
rows those are and who unblocks them. Do not redo a `CLOSED` row: its evidence
column names a commit or a measurement you can re-run.

## §1 Open work

Status values: `OPEN` (something remains, the row says what) · `ACCEPTED`
(measured, deliberately not fixed, escape routes disproved) · `CLOSED` (done,
evidence names where).

**How this table is counted.** P60's report said 35 rows / 19 open and an
independent grep said 38 / 20, because the rule had never been written down.
It is this, and nothing else:

* **Scope** is this section only — between the `## §1` heading and the next
  `## §` heading. `§2`, `§3` and `§4` rows are not debt rows and are never
  added in.
* **A row** is a line that starts with `| ` and splits into exactly **five**
  cells, whose first cell is a backticked `DBT-` id. The header and the
  `|---|` rule are not rows.
* **Malformed rows are reported, never dropped.** `DBT-P56-002` has four
  cells; it is named in the count rather than silently excluded, which is how
  a row can go missing.
* **Open** means the status cell, stripped of `*` and whitespace, begins with
  `OPEN`. `OPEN by design` is open. `ACCEPTED` and `CLOSED` are not.

Reproduce it:

```bash
python3 - <<'EOF'
import re
sec = re.split(r"^## ", open("docs/LEDGER.md").read(), flags=re.M)
body = next(x for x in sec if x.startswith("§1 "))
rows = [r for r in body.splitlines() if r.startswith("| `DBT-")]
cells = [[c.strip() for c in r.strip().strip("|").split("|")] for r in rows]
good = [c for c in cells if len(c) == 5]
bad = [c[0] for c in cells if len(c) != 5]
op = [c[0] for c in good if c[2].strip("*").startswith("OPEN")]
print(f"rows {len(good)}  open {len(op)}  malformed {len(bad)} {bad}")
EOF
```
