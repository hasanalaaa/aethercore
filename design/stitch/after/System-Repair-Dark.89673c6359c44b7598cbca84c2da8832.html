System Integrity Repair

Execute diagnostic commands to verify and repair critical operating system files.

warning Mandatory Pre-requisite

A system restore point must be created before executing structural repairs to ensure rollback capability in case of unexpected corruption.

Deployment Image Servicing and Management

TOOL: DISM.exe
terminal

DISM prepares, modifies, and repairs Windows images. In the context of system repair, it is used to service the Windows component store itself, ensuring the source files used for repairs are healthy.

> DISM /Online /Cleanup-Image /RestoreHealth

Workflow Breakdown

  • • Checks component store for corruption.
  • • Records corruption to C:\Windows\Logs\CBS\CBS.log.
  • • Attempts automatic repair using Windows Update as source.

System File Checker

TOOL: SFC.exe
find_in_page

SFC scans the integrity of all protected system files and replaces incorrect versions with correct Microsoft versions. It should typically be run after DISM has verified the component store.

> sfc /scannow

Workflow Breakdown

  • • Verifies file signatures of protected OS files.
  • • Extracts clean copies from the component store if corrupted.
  • • Requires reboot if locked files are replaced.
